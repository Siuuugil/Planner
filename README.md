# 마이플래너 (MyPlanner)

일정, 업무, 기타 할 일, 게임 스펙업을 한곳에서 관리하는 Flutter 앱. Android, Windows(PC), 웹에서 동작합니다.

## 기능

4개 탭: **홈 · 캘린더 · 할 일 · 메이플**

- **홈**: [일상·업무]와 [게임]을 나눠서 표시 (게임은 보라색), 진행률, 결정석·캐릭터 위젯
- **게임 숨기기 (회사 모드)**: 홈 상단 게임 아이콘이나 설정에서 켜면 게임 일정·숙제·메이플 탭이 사라짐 (기기별)
- **캘린더**: 일정과 마감일 있는 할 일 함께 표시, 게임 일정은 보라 점·별도 목록
- **반복**: 일정·할 일에 매일 / 평일 / 매주 / 격주 / 매월 (+ 끝나는 날)
  - 반복 일정은 날짜마다 펼쳐 보이고, 완료는 그 날짜만. 삭제할 때 "이날만 빼기 / 전체 삭제"
  - 반복 할 일은 끝내면 사라지지 않고 마감이 다음 회차로 넘어감 (예: 매주 금 주간보고)
- **할 일**: 업무·개인 할 일 [전체 | 업무 | 개인] 필터, 빠른 추가, 마감일·D-day, 완료 접기
  - **단계(체크리스트)**: 할 일 안에 단계를 넣고 체크·순서 바꾸기, 목록에 '단계 2/4'
- **메이플**: 캐릭터 카드 + [숙제 | 결정석 | 성장 | 목표], 다른 게임도 숙제 탭에서 관리
  - 게임별 **일일/주간 숙제**: 게임마다 초기화 시각(기본 오전 6시)과 주간 초기화 요일(기본 수요일)을 설정하면 시간이 지나면 자동으로 다시 미완료가 됨
  - **스펙업 목표**: 시작값 → 현재값 → 목표값, 진행률 바, 마감일 D-day
  - 게임에 연결된 다가오는 일정
- **메이플스토리 캐릭터 연동** (넥슨 Open API, 설정에서 API 키 입력)
  - 닉네임 검색 → 캐릭터 이미지·레벨·경험치·직업·월드·길드·전투력
  - 레벨·전투력 목표를 만들면 현재값이 캐릭터 갱신 때 자동으로 채워짐
  - 성장 기록 그래프 (레벨/전투력), 지난 14일 기록 불러오기
  - **심볼**: 레벨/만렙·성장치·만렙까지 남은 날 (아케인·어센틱, 하루 개수 설정), 만렙 아닌 심볼이 있으면 '심볼 일일' 숙제가 자동으로 생기고 다 만렙이면 사라짐
  - **이벤트**: 진행 중인 이벤트 공지(숙제 탭), 끝나는 날이 캘린더에 자동으로 들어감 (지운 건 다시 안 넣음)
  - 주요 스탯, 장착 장비(스타포스·잠재능력)
  - API 키는 기기에만 저장, 캐릭터·기록은 계정에 동기화
- **💎 결정석 수익** (게임 탭)
  - 화면 구성: 이번 주 요약 → [보스 고르기] [가격표] 버튼 → 캐릭터별 이번 주 보스 체크 → 월간 보스 → 주간 수익 기록
  - 보스 선택 화면: 캐릭터별로 보스마다 난이도 칩을 눌러 선택, 파티 인원, 1인당 가격
    - 결정석 4천만 이하는 목록에서 뺌 (노멀 루시드·윌·더스크·진 힐라·듄켈은 남김, 하드는 하드 스우부터)
  - **월간 보스(검은 마법사)는 따로**: 매월 1일 초기화, 주간 수익·통계·판매 한도(12개)에 안 섞임
  - 프리셋 버튼: 검밑솔 · 하세이칼 · 노적노칼 (규칙은 [maple.ygh.kr 보스 수익 계산기](https://maple.ygh.kr/boss-revenue)와 같음), 전체 해제
  - 에오스 캐릭터: 결정석 → 메포 → 본캐 월드 환산 (기본 ×0.55, 바꿀 수 있음), 넥슨 캐릭터 월드가 에오스면 자동 지정
  - 잡은 보스는 주간 퀘스트처럼 체크
  - 이번 주 수익/예상 수익, 캐릭터당 주간 판매 제한(12개) 경고, 주간 수익 기록 그래프·평균·누적
  - 메소 목표: 결정석 수익이 자동으로 쌓이고 "지금 속도면 N주 뒤" 예상
  - 가격표 기본값: [보스 결정 가격 정리](https://matsu1207.tistory.com/757) (2026.10.22 기준), 앱에서 수정 가능
  - 주간 초기화 알림에 남은 결정석 금액 표시
- **알림** (설정 ⚙️): 일정 시작 N분 전, 마감일·종일 일정 당일 아침, 게임 숙제 초기화 N시간 전에 남은 숙제
  - Android·Windows는 앱이 꺼져 있어도 울림, 웹은 페이지가 열려 있을 때만
- **AI 비서** (홈 ✨, PC 앱에서 내 컴퓨터의 Claude Code CLI 사용 — API 비용 없음)
  - 자연어 빠른 입력: "내일 3시 회의, 목요일까지 보고서" → 일정·할 일·게임 일정 미리보기 후 추가
  - 오늘 계획: 일정·할 일·숙제로 시간표 제안 (회사 모드면 게임 제외), 홈에 '다음 할 것'
  - **업무 코치**: 업무·개인 할 일과 2주 일정을 보고 우선순위, 큰 일 쪼개기, 회의·보고 준비, 메일 초안 (게임은 안 봄, 회사 모드에서도 보임)
    - 쪼갠 단계는 그 할 일 안의 단계로, 일정은 확인 카드로 제안 → '적용'을 눌러야 추가
  - 메이플 코치: 앱이 계산한 숫자(레벨업 예상일, 결정석, 보스별 내 몫, 목표 남은 주)로 답변
  - 주간 리포트: 지난 7일 돌아보기 + 다음 주 할 것
  - **AI 자동 실행** (PC가 켜져 있으면): 아침 브리핑(기본 8:30·평일)에 오늘 계획을 만들어 **PC 마을로 휴대폰 푸시·디스코드 DM**, 월요일엔 주간 리포트도. PC가 여러 대여도 하루 한 번
  - 대화: 질문·요청, 바꾸는 일은 확인 카드로 제안 → '적용'을 눌러야 반영
  - 결과는 모든 기기에 동기화
  - **폰·웹에서도 대화**: 보낸 질문을 같은 계정으로 켜져 있는 PC 앱이 받아 답함 (설정 → AI → "폰·웹 대화에 이 PC가 답하기")
    - PC가 여러 대 켜져 있어도(집 PC + 회사 노트북) 한 대만 답함. 내 목소리 서버가 켜진 PC가 먼저 잡고, 잡은 PC가 3분 넘게 못 끝내면 다른 PC가 이어받음
  - **🎤 음성 대화**: 폰·웹(크롬)에서 마이크 버튼 → 말하면 보내지고, 답은 소리로 읽어줌
    - 핸즈프리(🎧): 답을 다 읽으면 자동으로 다시 들음 → 계속 말로 대화
    - PC 앱도 답을 읽어줌. Windows 음성 인식은 한국어가 안 돼서 입력은 Win + H (Windows 음성 입력) 사용
  - **🗣 내 목소리**: AI 답을 내 목소리로 (GPT-SoVITS 학습 또는 Qwen3-TTS 복제, PC GPU에서 실행)
    - AI가 답마다 감정(보통·기쁨·차분·아쉬움·신남)을 고르고, 그 감정으로 녹음한 내 참고 음성의 말투를 따라 읽음
    - PC가 만든 음성은 계정 저장소에 올라가서 폰·웹에서도 같은 목소리로 들림
    - 설치·녹음·학습 방법: [voice_server/README.md](voice_server/README.md)
  - 대화 말투: 비서 / 친구 / 연인 (설정 → AI)
  - 폰 질문에 PC가 답하면 휴대폰·디스코드로도 알림 (선택)
  - 설정 → AI: claude 실행 파일 경로, 연결 확인
- **📥 수집함** (PC 마을과 연결): 떠오른 생각·링크를 바로 던져 두면 PC 마을이 디스코드 DM으로 "할 일로 / 마을 서재로 / 버리기"를 물어보고 정리
  - Android: 다른 앱(브라우저·유튜브·메모 등)에서 **공유 → 마이플래너** 를 누르면 바로 수집함에 들어감
  - 앱 안: 홈 상단 📥 아이콘(수집함 화면)이나 + 메뉴의 "📥 수집"에 한 줄 입력
  - **최근 수집 목록**: 수집함 화면에서 최근 50개와 상태(올리는 중 / PC 마을 대기 / 처리됨 ✓) 확인, 길게 누르면 복사. 다른 기기·앱에서 넣은 수집도 보임
  - 동기화 테이블에 `kind: 'inbox'` 행으로 올라감 (오프라인이면 연결될 때 올림)
- **다크 모드**: 설정 → 화면 → 테마 (시스템 / 밝게 / 어둡게, 기기마다)
- **백업**: 설정 → 백업 → 내보내기(JSON 파일) / 되돌리기(합치기 또는 그대로 되돌리기). PC는 매일 `문서\MyPlanner\backups`에 자동 백업 (최근 14개)
- **폰 ↔ PC 동기화** (Supabase): 이메일로 로그인하면 자동으로 맞춰짐
  - 오프라인에서도 그대로 사용 가능, 인터넷이 연결되면 밀린 변경을 올림
  - 다른 기기에서 바꾼 내용은 실시간으로 반영 (같은 항목을 양쪽에서 고치면 나중에 고친 쪽이 남음)
  - 로그인 안 해도 기기 안에서는 그대로 동작
  - 숙제·보스 체크는 따로 동기화돼서 두 기기에서 동시에 체크해도 안 덮어씀
  - 비밀번호 찾기: 메일 링크 → 웹에서 새 비밀번호
  - 웹에서 넥슨 API는 Supabase 중계 함수(nexon-proxy)를 거침 (로그인 필요)
  - GitHub Actions가 주 2회 Supabase에 접속해 무료 플랜 일시정지 방지

## 설치 (Flutter 필요 없음)

코드를 올리면 GitHub Actions가 자동으로 빌드해서 레포의 **Releases → 최신 빌드** 에 올려 둡니다.

- **PC (Windows)**: `MyPlanner-windows.zip` 받아서 압축 풀고 `my_planner.exe` 실행
  (바탕화면 바로가기 만들어 두면 끝. 새 버전은 같은 폴더에 덮어쓰기)
  - 창을 닫아도 **트레이(작업 표시줄 오른쪽 아래)** 에서 계속 실행, 아이콘 클릭으로 다시 열기 · 우클릭 → 완전히 종료
  - **윈도우 시작 시 자동 실행** (창 없이 트레이로). 설정 → PC 앱 에서 끄고 켜기
  - 이미 켜져 있을 때 exe 를 다시 실행하면 새로 켜지 않고 기존 창을 앞으로
  - 설정 → PC 앱 → "내 목소리 서버도 같이 켜기" (C:\MyPlannerVoice 설치 시)
- **Android**: `MyPlanner.apk` 받아서 설치 (처음 한 번 "출처를 알 수 없는 앱" 허용)
- **웹**: https://siuuugil.github.io/Planner/
  크롬 주소창의 "앱 설치" 아이콘으로 PC에 프로그램처럼 설치 가능

## 개발용 실행

[Flutter SDK](https://docs.flutter.dev/get-started/install) 설치 후:

```bash
flutter pub get
flutter run -d windows   # PC (Windows)
flutter run -d chrome    # 웹
flutter run              # 연결된 안드로이드 기기/에뮬레이터
```

빌드:

```bash
flutter build apk --release   # build/app/outputs/flutter-apk/app-release.apk
flutter build windows         # build/windows/x64/runner/Release/
flutter build web
```

## 동기화 설정

- Supabase 프로젝트: `game-planner` (서울 리전), 접속 정보는 `lib/config.dart`
- DB 스키마: `supabase/schema.sql` (`items` 테이블 + 본인 데이터만 접근하는 RLS)
- 가입 시 확인 메일의 링크를 한 번 눌러야 로그인됨. 번거로우면 Supabase 대시보드 →
  Authentication → Sign In / Providers → Email 에서 *Confirm email* 을 끄면 됨

## 구조

```
lib/
  main.dart                 앱 진입점, 테마, 한국어 로케일
  models/                   Schedule, Task, Game, Goal, Chore (+ 초기화 계산)
  data/                     AppStore(상태 + 저장 + 변경 추적), SyncService(Supabase 동기화)
  notify/                   알림 계획(reminders.dart)·예약(notify_service.dart)
  maple/                    넥슨 Open API 클라이언트·캐릭터 갱신
  ai/                       Claude CLI 연동, AI 프롬프트·상황 요약, 음성(인식·읽기·내 목소리)
  ui/kit.dart               테마와 공통 디자인 요소 (섹션 카드, 진행 막대, 체크 등)
  screens/                  홈 / 캘린더 / 할 일 / 메이플 (+ 캐릭터·결정석·게임 상세, 계정, 설정)
  widgets/                  타일과 추가·수정 다이얼로그
voice_server/                PC용 '내 목소리' 서버 (GPT-SoVITS / Qwen3-TTS)
test/                       초기화 계산·진행률·동기화 병합·알림 계획·화면 테스트
```
